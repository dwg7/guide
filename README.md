# dwg7 Guide

This repository hosts the public dwg7 Access Layer: a practical guide for understanding the UN Open GIS Initiative Domain Working Group 7 (dwg7), finding a suitable first path, and trying a small, visible experiment without reducing the work to recruitment or governance content.

## Public site

- Site: https://dwg7.opengis.org/guide
- Source entry: [docs/index.md](docs/index.md)

## Repository purpose

This repository is not a membership portal, an organization chart, or a roadmap for one product. It is a public access layer for explaining the context, culture, and entry points for engaging with dwg7 in a way that remains useful over time.

## Source location

The public guide content is maintained in the `docs/` directory. The content is written in English for the public product, while maintenance guidance and agent-facing notes are written in Japanese in [AGENTS.md](AGENTS.md).

## Key files

- [CONTRIBUTIONS.md](CONTRIBUTIONS.md) — how to contribute to the guide.
- [AGENTS.md](AGENTS.md) — permanent guidance for working on and editing this repository.
- [docs/index.md](docs/index.md) — public landing page for the guide.
- [docs/dwg7-in-5-minutes.md](docs/dwg7-in-5-minutes.md) — concise orientation for newcomers.
- [docs/onboarding-paths.md](docs/onboarding-paths.md) — role- and interest-based entry routes.
- [docs/good-first-experiments.md](docs/good-first-experiments.md) — low-barrier experiments.

- [docs/monthly-snapshot.md](docs/monthly-snapshot.md) — reusable monthly narrative template.

## Language policy

- Agent conversations, maintenance notes, and work reports are in Japanese.
- Public product pages in `docs/` are written in English.

## Contributing

Read [CONTRIBUTIONS.md](CONTRIBUTIONS.md). Suggestions, corrections, repeated experiments, and fresh checks are welcome through GitHub Issues or Pull Requests in this repository.

## GitHub Pages setup

This site is designed for GitHub Pages using the repository's `main` branch and the `/docs` folder. In GitHub, set:

1. Settings → Pages
2. Source: `Deploy from a branch`
3. Branch: `main`
4. Folder: `/docs`

This repository does not create a `docs/CNAME` file. The custom domain is assumed to be managed by the organization-level Pages configuration rather than by the repository itself.

## AGENTS guidance

[AGENTS.md](AGENTS.md) is the permanent editorial and maintenance guide for this repo. It defines the working stance: help people understand dwg7, connect to it, and try small, visible experiments without building a gatekeeping or recruitment layer.
